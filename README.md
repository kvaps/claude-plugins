# kvaps Claude Plugins

Personal collection of [Claude Code](https://claude.com/claude-code) plugins.

## Installation

Add the marketplace once:

```text
/plugin marketplace add kvaps/claude-plugins
```

Install any plugin from it:

```text
/plugin install <plugin-name>@kvaps-claude-plugins
```

## Plugins

### Hooks

| Plugin | Description |
| --- | --- |
| [**tmux-status**](hooks/tmux-status) | Reflect live Claude Code session state (starting / working / waiting / idle / error) as a colored dot in the tmux window status line |
